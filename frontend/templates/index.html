如何申请推特 (X) API 秘钥？

  1. 访问 developer.x.com 并用推特账号登录。
  2. 创建一个应用 (App)，在 **User authentication settings** 中将 Permissions 设置为 Read and Write（发推必须具有 Write 权限）。
  3. 在 **Keys and Tokens** 选项卡中，生成 **API Key & Secret** 以及 **Access Token & Secret**。
  4. 将 4 个秘钥粘贴至左侧表单，点击保存即可享受全自动推特运营！
